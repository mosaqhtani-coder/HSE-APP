# HSE PWA (غلاف)

تطبيق ويب قابل للتثبيت على الجوال يفتح لوحة Apps Script الحالية. لا يخزّن بيانات، ولا يحتوي أسرار.

## النشر على GitHub Pages
1. أنشئ مستودع جديد (Public)، مثلاً `hse-app`.
2. ارفع كل الملفات: `index.html` و`manifest.webmanifest` و`sw.js` و`offline.html` ومجلد `icons` (4 صور).
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يظهر الرابط: `https://<اسمك>.github.io/hse-app/`.

## التثبيت على الجوال
- أندرويد (Chrome): افتح الرابط ← قائمة النقاط الثلاث ← "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- آيفون (Safari): زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

## ملاحظات
- أول فتح يطلب تسجيل دخول جوجل (حسب صلاحية كل مستخدم).
- يحتاج إنترنت للقراءة؛ بدونه تظهر صفحة "لا يوجد اتصال".
- إذا غيّرت رابط نشر Apps Script، عدّل `APP_URL` داخل `index.html`.
